# INSIGHT Notification Core

INSIGHT参加者向けのnote通知アーカイブ／分析基盤です。

## 目的

- note通知を見逃しても履歴を残す
- スキ、コメント、返信、購入、チップ、マガジン追加、引用、「あなたの記事が話題です」、高評価、ポイント、その他通知を保存する
- 人物別・記事別・日別に集計する
- INSIGHTの既存会員認証を利用し、参加者ごとにデータ領域を分離する

## セキュリティ

- noteのパスワードやログインCookieは保存しません
- INSIGHTの会員トークンは既存の同一origin localStorageから参照し、サーバー側で既存INSIGHT APIへ照会して本人を確認します
- 通知DBはSupabaseのRLSを有効化し、クライアントからの直接参照権限を付与していません
- note側からの取り込みは専用の追加専用トークンを使い、再発行時に旧トークンを失効します

## v1

通知画面上の表示内容をブラウザ内で読み取り、通知本文と関連リンクのみを保存する方式です。自動同期はnote公式の外部向け通知APIが確認できないため、まず安全なブラウザ取り込み方式で実装しています。
